Deploy Kavalan Agent to Linux Server

Zero-dependency, standalone log collector (<12MB RAM). Supports systemd, live tailing of syslog, auth.log, and nginx/apache.

Option 1: One-Line Curl Installer (Ubuntu / Debian / RHEL)
curl -sSL http://127.0.0.1:8910/install.sh | sudo bash -s -- --manager http://127.0.0.1:8910 --name $(hostname)
Option 2: Remote Deployer via SSH (From Manager)
python3 kavalan-siem/deployer.py --target ubuntu@<SERVER_IP> --manager http://127.0.0.1:8910 --name ubuntu-srv01
ⓘ How it works: The agent registers with the Tier 2 Manager, obtains an authentication key, tails /var/log/auth.log and web access logs, batches normalized CEM JSON, and pushes via HTTP POST with automatic offline disk spooling.
